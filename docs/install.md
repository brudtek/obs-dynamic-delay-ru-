# Установка и удаление

Подходит для OBS Studio 32.2.x на Windows 10/11 x64. Проверено на OBS 32.2.2.

## Установка установщиком (проще всего)

1. Закройте OBS. Если она открыта, установщик попросит её закрыть.
2. Запустите `obs-dynamic-delay-1.2.1-ru-setup.exe`.
   - Windows может показать «Система Windows защитила ваш компьютер»: файл не
     подписан сертификатом издателя. Нажмите «Подробнее» → «Выполнить в любом случае».
   - Подтвердите запрос прав администратора: папка плагинов OBS защищена.
3. Дождитесь сообщения «Плагин установлен».
4. Запустите OBS и откройте **Док-панели → Управление задержкой**.

Установщик кладёт плагин в `C:\ProgramData\obs-studio\plugins\obs-dynamic-delay`
и заменяет предыдущую версию, в том числе исходный англоязычный OBS Dynamic Delay.
Повторный запуск обновляет плагин, настройки сохраняются.

Вместо setup.exe можно распаковать архив `obs-dynamic-delay-1.2.1-ru-windows-x64.zip`
в любую папку и дважды щёлкнуть `Установить.cmd` — результат тот же.

## Установка вручную

1. Закройте OBS.
2. Распакуйте из архива `obs-dynamic-delay-1.2.1-ru-windows-x64.zip` папку
   `obs-dynamic-delay` целиком в
   `C:\ProgramData\obs-studio\plugins\`
   (если папок `obs-studio\plugins` нет — создайте; папка `ProgramData`
   скрытая, путь проще вставить в адресную строку Проводника).
   Старую папку `obs-dynamic-delay` там, если есть, удалите.
3. Проверьте, что файлы лежат так:
   ```
   C:\ProgramData\obs-studio\plugins\obs-dynamic-delay\bin\64bit\obs-dynamic-delay.dll
   C:\ProgramData\obs-studio\plugins\obs-dynamic-delay\data\locale\ru-RU.ini
   ```
4. Запустите OBS и откройте **Док-панели → Управление задержкой**.

Папки `bin` и `data` по отдельности в папку установки OBS не копируйте.

## Удаление

- Если ставили установщиком: **Параметры → Приложения → Установленные
  приложения → «Управление задержкой для OBS» → Удалить**, или `Удалить.cmd`
  из архива.
- Если ставили вручную: закройте OBS и удалите папку
  `C:\ProgramData\obs-studio\plugins\obs-dynamic-delay`.

Настройки плагина, если они больше не нужны, лежат в
   `%APPDATA%\obs-studio\plugin_config\obs-dynamic-delay\settings.json`.
   Исходная версия 1.2.0 могла оставить там же `multistream.json` с ключами
   площадок открытым текстом — удалите его, если мультистримом пользовались.

## Перед первым эфиром

- **Отключите встроенную задержку OBS**: Настройки → Расширенные → Задержка
  трансляции. С ней плагин не включается и пишет об этом в панели.
- **Интервал ключевых кадров 1–2 секунды** (Настройки → Вывод → Трансляция →
  Интервал ключевых кадров). Переходы делаются по ключевому кадру: при
  интервале «авто» (до 8–10 секунд) переход в прямой эфир и начало накопления
  могут ждать столько же.
- **Сцена ожидания** — отдельная сцена (например, «Стоп кадры»). Её источники
  звука лучше не использовать в других сценах: тогда режим «Звук сцены»
  работает без ограничений. Если источник звучит где-то ещё, панель напишет
  об этом жёлтым блоком и заменит звук на тишину.
- **Память**: буфер хранит уже закодированный поток. При 6 Мбит/с задержка
  300 секунд займёт около 225 МБ. Ожидаемый расход панель показывает после
  запуска трансляции или записи.

## Как пользоваться

1. Запустите трансляцию как обычно.
2. Нажмите **Включить задержку**. Зрители видят сцену ожидания, полоса
   показывает «Накопление N%».
3. Когда буфер наберётся, состояние сменится на **Эфир с задержкой**, зрители
   видят изображение с отставанием на выбранное время.
4. **Снять задержку** — поток переходит на текущую живую картинку на ближайшем
   ключевом кадре, накопленное видео пропускается.
5. Повторное **Включить задержку** набирает буфер заново, с момента нажатия.
   Видео, которое уже показали, не повторяется.

Задержку можно включить и до начала трансляции: состояние «Задержка включится
при запуске» — накопление начнётся само, как только запустится трансляция или
запись. После перезапуска OBS настройки сохраняются, а задержка всегда
выключена.
