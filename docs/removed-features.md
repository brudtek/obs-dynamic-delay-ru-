# Удалённые функции

Перед удалением прослежены зависимости: каждый файл ниже используется только
мультистримом. Задержка основного выхода, звук сцены ожидания, предпросмотр и
настройки от них не зависят — это подтверждено сборкой без них и прогоном
всех оставшихся тестов и сценария в OBS.

## Мультистрим

| Что | Файлы | Почему можно удалить |
|---|---|---|
| Панель «Dynamic Delay — Multistream» | `src/multistream-dock.*` | Отдельная док-панель, регистрировалась в `plugin-main.cpp` отдельно от основной |
| Список площадок, ввод серверов и ключей, хранение в `multistream.json` | `src/multistream-controller.*` | Обслуживает только панель мультистрима |
| Собственный выход OBS для мультистрима и подбор кодировщиков | `src/multistream-controller.*`, `src/multistream-encoders.*` | Регистрировал свой тип выхода; основной выход трансляции и запись его не используют |
| Отправка по RTMP/RTMPS, очередь пакетов | `src/multistream-transport.*`, `src/core/multistream-queue.hpp` | Сетевой клиент только для площадок мультистрима |
| Вложенные librtmp и Happy Eyeballs, привязка к mbedTLS, zlib, FFmpeg, Qt6Network | `vendor/`, `cmake/common/multistream-dependencies.cmake` | Подключались только ради сетевого клиента |
| Методы контроллера задержки для «управляемых» выходов | `DelayController::add_managed_output`, `managed_output_started`, `remove_managed_output`, сигнал `about_to_shutdown` | Вызывались только из контроллера мультистрима |
| Приоритет «Multistream» в выборе потока для предпросмотра | `src/core/preview-timing.hpp` | Метка больше не встречается; порядок «Трансляция → Запись» сохранён |
| Тесты мультистрима | `tests/multistream_*.cpp`, `tests/verify-multistream.mjs` | Проверяли удалённый код |
| Лицензии вложенных библиотек | `data/licenses/librtmp-*`, `mbedtls-*`, `happy-eyeballs-*`, `zlib.txt`, `vendor/source-archives/` | Этих библиотек в сборке больше нет |

## Что сознательно оставлено

- **Внутренний выход сборщика пакетов** (`hold-pipeline`, тип выхода
  `obs_dynamic_delay_capture_output`). Внешне похож на мультистрим, но нужен
  основной задержке: кодирует сцену ожидания, пока набирается буфер.
- **Внутренний источник звука** (`hold-audio-tap`) — для звука сцены ожидания.
- **Пункт «Затемнение» в способе перехода** — недоступен, как и в исходнике
  (требует перекодирования). Оставлен, чтобы было видно, какие способы бывают.
- **`src/core/packet_delay.*`** — независимое ядро задержки без OBS, которое
  используется только тестами `packet_delay_tests`. В DLL не входит.
- **Тест `tests/verify-recording.mjs`** — проверяет записи интеграционного
  теста задержки, к мультистриму не относится.
