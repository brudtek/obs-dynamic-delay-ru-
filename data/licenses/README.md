# Лицензия

«Управление задержкой» (русская упрощённая сборка OBS Dynamic Delay 1.2.1)
распространяется на условиях **GNU GPL версии 2 или любой более поздней**,
без каких-либо гарантий. Полный текст — `obs-dynamic-delay-GPL-2.0.txt`.

Исходный плагин OBS Dynamic Delay 1.2.0 — © Aritz,
https://github.com/stanixdor/obs-variable-delay (тег `1.2.0`).
Изменения 23.11.2026 перечислены в `CHANGELOG.md` исходников.

Исходный код этой сборки и сценарии сборки передаются вместе с бинарным
комплектом (архив `obs-dynamic-delay-1.2.1-ru-source.zip`).

Сторонние библиотеки в DLL не встроены. Плагин использует библиотеки самой
OBS Studio (libobs, obs-frontend-api, Qt 6), которые распространяются вместе
с OBS под их собственными лицензиями.
